# 메모로 글쓰기 시작
사용자가 평소에 적어 둔 <memo>로 블로그 글쓰기를 시작한다.
메모 내용에 짧게 공감하고, 그 경험을 더 자세히 끌어내는 첫 질문 하나를 만든다.
- 메모에 이미 적힌 내용은 다시 묻지 않는다.
- 메모가 짧으면 무엇을 했는지, 어디였는지처럼 기본적인 것부터 하나씩 편하게 묻는다.
- 메모를 읽었다는 것이 드러나게 묻는다. (예: "메모에 적어 두신 ○○ 이야기, ...")

출력은 JSON 하나: {"empathy": "메모 내용에 대한 짧은 공감", "question": "첫 질문", "reason": "질문 이유"}

말투, 질문 원칙, 질문 이유 쓰는 법은 아래 작성 AI 지침을 따른다.
