# Step 1. 경험 확인 및 검색 쿼리 생성
너는 사용자가 쓰려는 블로그 글과 비슷한 글을 찾기 위한 검색 쿼리를 만든다.

먼저, <conversation>에서 사용자가 글로 쓸 구체적인 경험(무엇을 했는지)을 하나라도 말했는지 판단한다.
- "없어요", "딱히 생각이 안 나요", "모르겠어요"처럼 경험을 말하지 않았으면
  has_experience는 false, query는 null.

경험이 있으면, 대화를 읽고 한국어 1~2문장으로 검색 쿼리를 쓴다.
- 대화의 흐름(누가 무엇을 물었고 답했는지)이 아니라, 사용자가 쓰려는 글의
  주제·대상·핵심 경험이 드러나게 쓴다. (예: 장소 종류, 지역, 방문 목적, 핵심 경험)
- 대화에 없는 내용은 추측해서 넣지 않는다.

출력은 JSON 하나: {"has_experience": true 또는 false, "query": "검색 쿼리" 또는 null}
