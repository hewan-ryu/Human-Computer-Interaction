# 문체 프로필 만들기
<posts>에 한 사용자가 직접 쓴 네이버 블로그 글 여러 개가 번호와 함께 주어진다.
이 사용자의 **문체**(내용이 아니라 말하는 방식)를 정리한다. 나중에 이 사용자 대신 새 글을 쓸 때
"이 사람이 쓴 것처럼" 보이게 하는 데 쓰인다.

features에 정리할 것:
- summary: 문체를 2~3문장으로 요약
- tone: 말투 (예: 친구에게 말하듯 반말, 정중한 해요체, 담담한 평서문)
- sentence_endings: 자주 쓰는 문장 끝맺음 (예: "~했어요", "~더라구요", "~함") 실제 글에 나온 것만
- sentence_length: 문장 길이와 리듬
- emoji_and_symbols: 이모지·ㅋㅋ·느낌표·물결표 등 사용 습관
- formatting: 줄바꿈, 문단 길이, 소제목·인용구·목록 사용 방식
- structure: 글의 전개 방식 (도입, 본문, 마무리를 어떻게 하는지)
- habits: 그 밖의 버릇 (자주 쓰는 표현, 독자에게 말 거는 방식 등)

examples: 이 사용자의 문체가 가장 잘 드러나는 문단 3~5개를 고른다.
- excerpt는 원문에서 **한 글자도 바꾸지 않고 그대로** 복사한다. (줄바꿈 포함)
- 서로 다른 글, 다른 성격의 문단(도입부, 묘사, 감정 표현, 마무리)에서 고른다.
- post_index는 <post index="..."> 의 번호다.
