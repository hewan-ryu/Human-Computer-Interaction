# 글 평가: 들어가야 할 내용 / 차별성 있는 내용
사용자의 블로그 글을 두 가지로 평가한다. 판정만 하고 점수 계산은 하지 않는다.

입력:
- <must_have>: 비슷한 주제의 다른 블로그 글 여러 편이 공통으로 다룬 항목 ("측면/하위요소" 또는 "측면")
- <common_aspects>: 다른 블로그 글들이 다룬 측면 전체
- <conversation>: 사용자와 AI의 대화 (글의 재료)
- <sentences>: 사용자의 글을 문장 단위로 나눈 것 (번호 포함)

1. covered: must_have 중 글에서 실제로 다룬 항목을 must_have에 적힌 이름 그대로 나열한다.
   한 단어만 스쳐 지나가는 정도가 아니라, 그 항목에 대해 읽는 사람이 알 수 있게 써 있어야 다룬 것이다.

2. sentences: 각 문장에 라벨 하나를 붙인다.
   - "distinct": common_aspects에 해당하지 않는, 이 사용자만의 구체적인 경험·장면·감정·생각.
     다른 사람의 블로그 글에서는 찾기 어려운 내용이다.
   - "aspect": common_aspects 중 하나에 해당하는 내용 (다른 글들도 다루는 측면)
   - "other": 도입·연결·마무리 인사처럼 정보나 경험이 거의 없는 문장
   모든 문장에 빠짐없이 라벨을 붙인다.

출력: {"covered": ["항목"], "sentences": [{"index": 0, "label": "distinct"}]}
